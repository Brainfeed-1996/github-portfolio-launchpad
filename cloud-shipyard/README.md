# Cloud Shipyard

Infrastructure-as-code orchestration, environment lifecycle, policy checks, and multi-cloud deployment control plane.

## Positioning

Cloud Shipyard is a serious platform engineering and DevOps portfolio project built around infrastructure lifecycle management.

## Differentiation

- demonstrates cloud architecture, IaC, policy, release workflows, and environment management
- attractive for platform, SRE, and developer-experience roles

## Core capabilities

- environment templates and drift detection
- deployment workflow engine
- policy gates for infra changes
- cost and quota awareness
- preview environments and teardown workflows

## Suggested stack

- Go, TypeScript, or Python control plane
- Terraform or Pulumi integrations
- Postgres plus queueing backend

## High-ROI signal

Very strong for cloud-native and internal platform teams.
