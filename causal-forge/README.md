# Causal Forge

Causal inference and decision-simulation platform for counterfactual analysis, intervention modeling, experiment interpretation, and decision-support systems.

## Why this project matters

Causal Forge introduces a very different class of engineering problem into the portfolio: systems that must reason not only about correlation, but about interventions, causal structure, and decision consequences.

## Core capabilities

- causal graph modeling
- intervention simulation
- counterfactual query workflows
- experiment interpretation tooling
- scenario comparison and sensitivity analysis

## Suggested stack

- Python for modeling
- Rust or Go for serving and simulation performance
- TypeScript for interactive causal exploration

## High-ROI signal

Excellent differentiation for data science platforms, experimentation systems, decision intelligence, and advanced analytics roles.
