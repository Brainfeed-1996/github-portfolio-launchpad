# Compiler Garden Roadmap

## Near term

- finalize language grammar
- implement typed AST and semantic passes
- define IR contracts
- add interpreter or bytecode VM
- improve diagnostics with span-rich errors

## Mid term

- optimization passes
- module system
- REPL or playground
- source maps and debug tooling
- conformance test suite

## Long term

- alternate backend experiment
- generics or richer type features
- static analysis lints
- language server integration
