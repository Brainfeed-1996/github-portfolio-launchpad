# GitHub Profile Plan

## Profile repository

Create a special profile repository named exactly after your GitHub username.

## Profile README should include

- concise positioning statement
- flagship projects
- selected supporting projects
- technical domains
- security, systems, AI, cloud, product, and tooling focus
- architecture mindset
- links to talks, writeups, demos, and benchmarks when available

## Tone

Confident, technical, concrete.

Avoid inflated self-description. Let the work carry the weight.

## Example positioning

Security-first engineer building reliable systems, offensive and defensive tooling, AI evaluation frameworks, and production-grade developer platforms.

## Sections to include

- About
- Core domains
- Featured repositories
- Principles
- Current build focus
- Contact
