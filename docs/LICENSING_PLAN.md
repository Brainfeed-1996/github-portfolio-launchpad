# Licensing Plan

## Default recommendation

Use permissive licenses for portfolio leverage unless you have a strategic reason not to.

## Recommended defaults

### MIT
Use for small libraries, utilities, templates, examples, and developer tools.

### Apache-2.0
Use for larger platforms, infrastructure, security tooling, and projects where explicit patent grant is valuable.

### GPL-3.0
Use only if you intentionally want strong copyleft.

## Suggested mapping

- Sentinel Fabric: Apache-2.0
- Adversary Forge: Apache-2.0
- Orchestra Mesh: Apache-2.0
- small utilities and templates: MIT
- research-heavy repos: MIT or Apache-2.0 depending on scope

## Note

For security projects, add a carefully written SECURITY.md and Responsible Disclosure section even when the repo is not a product.
