## Archive or de-emphasize in waves

### Wave 1, tutorial and weak-signal repos

Archive or at least de-prioritize repos that are primarily:

- tutorial coursework
- early beginner exercises
- generic CRUD or toy apps
- duplicate game or duplicate training repos
- weakly named experiments with no meaningful README

### Wave 2, near-duplicates and noisy variants

Consolidate or archive duplicate narratives such as:

- repeated frontend exercises
- multiple simple game implementations
- repeated training repos from courses
- generic collections without a strong curatorial reason

### Wave 3, keep but stop featuring

Keep public if useful historically, but do not surface them on profile or README.

## Description policy

Every visible serious repository must have:

- a precise one-line description
- a README that states why it exists
- an explicit status section

## Industrial portfolio rule

Your visible public portfolio should feel intentionally curated, not exhaustively dumped.
