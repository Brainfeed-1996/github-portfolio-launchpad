# Packet Weaver Roadmap

## Near term

- packet schema and session model
- ACK and retransmission path
- basic multiplexed streams
- degraded-network simulator
- metrics collection for latency and loss

## Mid term

- congestion or flow-control experiments
- trace visualizer
- fairness tuning across streams
- workload benchmark suite
- protocol fuzz testing

## Long term

- alternate transport heuristics
- adaptive retransmission strategies
- interop harness for protocol versions
- richer observability exports
