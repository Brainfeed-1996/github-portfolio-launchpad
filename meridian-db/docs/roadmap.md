# Meridian DB Roadmap

## Near term

- page and segment format
- WAL or journal implementation
- point lookup path
- basic B-tree or LSM index
- restart recovery tests

## Mid term

- snapshot reads
- simplified MVCC or isolation model
- range scan optimizations
- benchmark scenarios
- query parser experiments

## Long term

- compaction or vacuum concepts
- richer isolation guarantees
- secondary indexes
- storage introspection tooling
