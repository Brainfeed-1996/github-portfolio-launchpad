# Meridian DB

Storage engine and database systems project focused on indexing, transactions, snapshots, concurrency, and query execution fundamentals.

## Why this project matters

Meridian DB is designed to demonstrate deep systems engineering around data storage correctness and performance, which is one of the clearest signals of strong backend and infrastructure talent.

## Core capabilities

- page and segment storage model
- write-ahead logging or append journal
- B-tree or LSM-backed indexing
- snapshot reads and simplified MVCC
- recovery semantics
- query planning primitives
- benchmark harness

## Suggested stack

- Rust or C++
- criterion or custom benchmark suite
- optional SQL-like parser layer
