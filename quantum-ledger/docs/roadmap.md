# Quantum Ledger Roadmap

## Near term

- formalize ledger account and journal schemas
- add idempotent posting flow
- build balance projection model
- define reconciliation mismatch taxonomy
- implement sample settlement batch lifecycle

## Mid term

- multi-currency support
- partial failure handling for external processors
- dispute and reversal workflow support
- stronger audit export surfaces
- benchmark harness for throughput and recovery

## Long term

- configurable posting rules by product line
- explainable reconciliation engine
- compliance and regulator reporting packs
- historical replay for incident forensics
